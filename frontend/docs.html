Drop-in API key authentication

Set two environment variables, paste the middleware, and your service is protected.

Middleware

Express middleware (copy & paste)

This middleware validates your API key and blocks unauthorized requests.

AUTH_SYSTEM_URL=https://your-auth.example.com
const authMiddleware = (requiredService = null) => async (req, res, next) => {
  const apiKey = req.headers['x-api-key'] || req.headers.authorization?.replace('Bearer ', '');
  if (!apiKey) {
    return res.status(401).json({ message: 'Missing API key' });
  }

  const response = await fetch(`${process.env.AUTH_SYSTEM_URL}/api-keys/validate`, {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${apiKey}`
    }
  });

  const data = await response.json();

  if (!data.valid) {
    return res.status(403).json({ message: 'Invalid API key' });
  }

  if (requiredService && (!data.services || !data.services.includes(requiredService))) {
    return res.status(403).json({ message: 'Service not allowed' });
  }

  req.tenantId = data.tenantId;
  req.authKeyId = data.keyId;
  next();
};

module.exports = authMiddleware;

Uses the built-in `fetch` in Node 18+. For older Node versions, install `node-fetch`.

const express = require('express');
const authMiddleware = require('./authMiddleware');

const router = express.Router();

router.get('/billing', authMiddleware('billing'), (req, res) => {
  res.json({ tenantId: req.tenantId, message: 'Billing access granted' });
});

module.exports = router;

Important: Store API keys in server-side env variables only. Never expose them in frontend code.

Client

Send the API key from your service

Keep the API key in your server environment and attach it to outgoing requests.

AUTH_API_KEY=your_api_key_here
const response = await fetch('https://your-service.example.com/resource', {
  headers: {
    Authorization: `Bearer ${process.env.AUTH_API_KEY}`
  }
});

Validate API keys manually

Use this endpoint if you want to build your own validation logic.

POST /api-keys/validate
Authorization: Bearer <apiKey>
