Quick Start

🚀 3-Step Integration

Add secure authentication to your website in less than 2 minutes.

Step 1: Include SDK Script and CSS 
<!-- Include in the <head> of your page -->
<link rel="stylesheet" href="https://your-auth-server.com/sdk/rishiraj-auth-modal.css">

<!-- Include at the bottom of the <body> -->
<script src="https://your-auth-server.com/sdk/rishiraj-auth.js"></script>
Step 2: Initialize Rishiraj-Auth Client Instance 
const auth = new RishirajAuth({
  tenantId: "YOUR_TENANT_ID",
  environment: "DEVELOPMENT", // or "PRODUCTION"
  serverUrl: "https://your-auth-server.com",
  onLogin: (user, tokens) => {
    console.log("Logged in successfully:", user);
  }
});
Step 3: Trigger Login Modal Anywhere 
<button onclick="auth.showLoginModal()">Log In / Register</button>

📦 Client SDK Reference

Comprehensive API documentation for the `RishirajAuth` class instance.

Class Constructor Options

OptionTypeDefaultDescription
tenantIdstring (UUID)RequiredTenant UUID registered in the Developer Console.
environment"DEVELOPMENT" | "PRODUCTION""DEVELOPMENT"Environment mode. Segregates rate limits & user profiles.
serverUrlstringwindow.location.originDomain where the Rishiraj-Auth server is hosted.
onLoginfunction(user, tokens)undefinedCallback fired when authentication completes.
onLogoutfunction()undefinedCallback fired when user signs out.
onTokenRefreshfunction(tokens)undefinedCallback fired when credentials auto-refresh.

Available Methods

auth.showLoginModal()

Injects and displays a dark-theme registration, login, and forgot password modal inside the host webpage.

auth.logout()

Logs the user out, revokes the refresh token on the server, clears stored session states, and triggers onLogout.

auth.getUser()

Returns the cached user object: { userId, email, name, avatar, isVerified, tenantId }.

auth.getTokens()

Returns active credentials object: { accessToken, refreshToken }.

Backend

🛡️ Express Middleware Protection

Protect your custom Express endpoints by validating API keys cross-origin.

authMiddleware.js 
const authMiddleware = (requiredService = null) => async (req, res, next) => {
  const apiKey = req.headers['x-api-key'] || req.headers.authorization?.replace('Bearer ', '');
  if (!apiKey) {
    return res.status(401).json({ message: 'Missing API key' });
  }

  try {
    const response = await fetch('https://your-auth-server.com/api-keys/validate', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ apiKey })
    });

    const data = await response.json();

    if (!response.ok || !data.valid) {
      return res.status(403).json({ message: 'Invalid or Revoked API key' });
    }

    if (requiredService && (!data.services || !data.services.includes(requiredService))) {
      return res.status(403).json({ message: 'Forbidden: required service scope missing' });
    }

    req.tenantId = data.tenantId;
    req.environment = data.environment;
    next();
  } catch (err) {
    return res.status(500).json({ message: 'Validation server error' });
  }
};

module.exports = authMiddleware;

Config

⚙️ Segregated Environments

How Development and Production tenant layers operate.

🟢 Development Mode

Used for staging & sandbox integration. Verbose logging enabled. Relaxed rate limits. Users active upon registration.

🔵 Production Mode

Strict production isolation. Strict API rate limits. Enforced email verification gates before account activation.

Frontend

🔌 React / Next.js Integration

Quick setup snippet for React applications.

import React, { useEffect, useState } from 'react';

export default function AuthButton() {
  const [authClient, setAuthClient] = useState(null);
  const [user, setUser] = useState(null);

  useEffect(() => {
    import('https://your-auth-server.com/sdk/rishiraj-auth.js').then(() => {
      const auth = new window.RishirajAuth({
        tenantId: "YOUR_TENANT_UUID",
        environment: "DEVELOPMENT",
        onLogin: (u) => setUser(u),
        onLogout: () => setUser(null)
      });
      setAuthClient(auth);
      setUser(auth.getUser());
    });
  }, []);

  if (user) {
    return (
      <div>
        <p>Welcome, {user.email}</p>
        <button onClick={() => authClient.logout()}>Sign Out</button>
      </div>
    );
  }

  return (
    <button onClick={() => authClient?.showLoginModal()}>
      Sign In
    </button>
  );
}
Security

🔒 Security & Token Caching Guidelines

Recommended security standards for client and server implementation.

  • Keep API Keys Private: Never expose master API secret keys in frontend public source code or public repositories.
  • Automatic Silent Refresh: The SDK automatically schedules silent refresh timers before access token expiration.
  • Instant Session Revocation: Monitor and revoke compromised sessions live from the Developer Dashboard.
